## Parent

#3 团队文档归档系统（全量文档库）技术方案

## What to build

建立系统的真相源：SQLite 数据库 schema。复用 014 的四张表（documents / versions / occurrences / projects），新增 images / videos 两张独立实体表 + document_images 关联表。图片和视频是独立顶层实体（与文档平级），各自 `IMG-####` / `VID-####` ID 分配逻辑。建库、插入、读回一条记录全链路可跑。

## Acceptance criteria

- [ ] 迁移脚本建出空库，包含 documents/versions/occurrences/projects/images/videos/document_images 七张表
- [ ] 图片 ID 按 `IMG-####` 四位顺序分配（从 0001 起，永不改号、永不复用）
- [ ] 视频 ID 按 `VID-####` 分配
- [ ] 能插入并读回一条文档、一张图片、一条视频、一条文档↔图片关联
- [ ] 关联项目标签有存储位（单归属 project_id + 关联项目标签，具体存法 JSON 列或 tag 表可在此票定）
