## Parent

#3 团队文档归档系统（全量文档库）技术方案

## What to build

把真相源（SQLite）里的正文 + caption + 视频简介文本分块，用 bge-m3 向量化，写入云端 WeKnora；分类（五类 + 项目 + 图片/视频）建成 WeKnora 标签（custom_metadata 不能检索过滤，已核源码）。

## Acceptance criteria

- [ ] SQLite 正文/caption/简介文本导出为分块
- [ ] bge-m3 向量化写入云端 WeKnora
- [ ] 五类 + 项目建成 WeKnora 标签（项目/类别/图片/视频四类标签）
- [ ] WeKnora 里能搜到一篇文档的正文片段（内容检索）

## Blocked by

- #014 数据全量只读迁移
- #摄入与去重管道
- #文档转 md + 图片抽取
- #媒体实体登记（图片+视频）

## Further notes

WeKnora 部署在腾讯云 Lighthouse 官方镜像（4核8GB），需先在 `/wizard` 开通实例 + 拿 API key（SiliconFlow bge-m3、智谱 GLM-4V-Flash、SiliconFlow PaddleOCR-VL）。
