## 决议

**开发测试期 = 全云端，本地硬件部署延后到测试靠谱后的第二阶段。**

用户拍板：开发测试期间，图片、视频、向量数据库（WeKnora）都租云端；等测试靠谱了再本地买硬件、部署硬件。

- **WeKnora**：走腾讯云 Lighthouse 官方 WeKnora 镜像（2026-06 上线，已核官方镜像更新记录 + firstboot.sh 自动生成密钥 + docker compose up -d）。4核8GB = 245 元/月起步。
- **图片/视频存储**：腾讯云 COS（对象存储）。
- **图片/视频概述 + OCR**：云端 VLM API（具体选型见 #5 的 reframe）。
- **现有三台机器**：开发测试期只做开发与客户端，不承担推理/存储职责。

**推论**：原「硬件分工」中的 GPU 节点（Windows 3070）与常开服务（Mac mini）在开发测试期都不再用——这改变了 #5 的前提（从"本地 GPU 选型"变为"云端 VLM API 选型"）。

**本地采购部署**进入 Out of scope（第二阶段另开图）。
